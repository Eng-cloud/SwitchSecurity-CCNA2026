# Layer 2 Security

مشروع تعليمي تفاعلي عن أمان الطبقة الثانية (Layer 2) في CCNA 200-301: Port Security، DHCP Security (Snooping + DAI)، وSTP Security.

الفكرة إن كل موضوع ما يبدأ بالشرح المباشر، يبدأ بـ "ليش أصلاً احتجنا هالتقنية" ثم الهجمة اللي تحلها، وبعدها محاكاة تقدر تجرّبها بنفسك بدل ما تقرأ بس.

## ملاحظة تقنية

أوامر Cisco والسلوك الموصوف مبني على CCNA 200-301 القياسي. بعض التفاصيل (زي معدّلات rate-limit أو أسماء أوامر معينة) ممكن تختلف شوي حسب موديل الجهاز وإصدار IOS، فلا تعتمد عليها 100% بدون ما تتأكد بنفسك من `show` commands أو Packet Tracer.
