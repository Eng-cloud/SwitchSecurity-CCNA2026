# منصة الحلقات — Frontend Simulation

تنفيذ كامل لوثيقة **Halaqat Frontend Master Specification v2**: موقع Web حقيقي قابل للتشغيل
والتجربة يحاكي المنصة من منظور المستخدم، ببيانات وخدمات وهمية بالكامل (Mock) بدل Backend حقيقي.

> **لا يوجد خادم ولا ذكاء اصطناعي حقيقي ولا تسجيل صوت فعلي.** كل البيانات تُولَّد محليًا في
> المتصفح، وكل نتيجة تسميع محاكاة مُعلَّمة بوضوح داخل الواجهة نفسها.

---

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173
```

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | تشغيل بيئة التطوير |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run preview` | معاينة نسخة الإنتاج (المنفذ 4173) |
| `npm test` | اختبارات الوحدة (Vitest) |
| `npm run test:e2e` | اختبارات E2E (Playwright) على سطح المكتب والجوال |
| `npm run test:all` | الاثنان معًا |

```
Page → Hook (useAsyncData) → Service → Mock API → Mock Data
```

## ما الذي يعمل فعليًا

- **رحلة كاملة**: Landing → Login → OTP → Dashboard → صفحات الدور → إجراءات → نتائج →
  تقارير → إعدادات → Logout → Login مرة أخرى.
- **خمسة أدوار** لكل منها تنقل ولوحة وصفحات وبيانات وإجراءات مختلفة.
- **المصحف**: سور وأجزاء وبحث وعلامات وآخر موضع وتكبير وتفسير وتلاوة (محاكاة) وتحميل
  للقراءة دون اتصال مع محاكاة قطع الاتصال.
- **التسميع**: اختيار المقطع → تسجيل → مؤقّت وموجة صوتية → إيقاف → تحليل → نتيجة قابلة
  للحفظ، مع بيان صريح أن التحليل تجريبي.
- **الاختبارات**: تعليمات → أسئلة مولّدة → مؤقّت → تأكيد الإنهاء → نتيجة ومراجعة الإجابات.
- **التقارير**: فترات وتصفية ورسوم وجداول ومعاينة طباعة مع رأس وتذييل مخصصين.
- **الإعدادات**: الحساب، المظهر، الإشعارات، إمكانية الوصول، الجلسات، المساعدة.

## الوصول (Accessibility)

مستهدف التصميم والاختبار **WCAG 2.2 AA**:

- HTML دلالي، معالم بأسماء مميزة، عنوان `h1` واحد لكل صفحة، وإعلان تغيّر الصفحة لقارئ الشاشة.
- تنقل كامل بالكيبورد، مؤشر تركيز ظاهر دائمًا، حصر التركيز في النوافذ وإرجاعه بعد الإغلاق.
- لا تعتمد أي معلومة على اللون وحده (أيقونة + نص + لون)، ولكل رسم بياني بديل نصي كجدول.
- لا تعتمد أي معلومة على الصوت وحده — لكل حالة صوتية مقابل بصري.
- إعدادات وصول قابلة للتجربة: حجم النص، التباين المرتفع، تقليل الحركة، والمظهر — وتُحفظ
  في المتصفح.
- احترام `prefers-reduced-motion` و`prefers-color-scheme` من النظام مع الاستجابة لتغيّرهما مباشرة.

## ملاحظات على المحتوى

- **النص القرآني**: السور المتضمَّنة نصها كامل ومحقّق (الفاتحة و93–97 و99–114). بقية السور
  تعرض واجهتها كاملة مع إشعار صريح بأن النص غير متضمَّن في النسخة التجريبية — لا يوجد أي
  نص قرآني مولَّد أو وهمي.
- **التفسير**: نص عرض تجريبي مُعلَّم بوضوح، وليس منقولًا عن مصدر تفسيري.
- **أرقام الصفحات والأجزاء**: إرشادية للعرض حسب ترقيم مصحف المدينة.
- **بقية البيانات** (طلاب، حلقات، جلسات، درجات): مولّدة حتميًا وغير حقيقية.

## الحدود المعروفة

- لا يوجد Backend ولا تخزين خارج `localStorage` الخاص بالمتصفح.
- تحليل التسميع محاكاة حتمية مبنية على المقطع المختار، وليس تحليلًا صوتيًا.
- التلاوة والتسجيل محاكاة واجهة بلا ملفات صوتية أو وصول للميكروفون.
- الأدوار تجربة واجهة فقط ولا تمثل تفويضًا أو صلاحيات حقيقية.
