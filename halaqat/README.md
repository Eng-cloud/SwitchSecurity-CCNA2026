# منصة الحلقات — Frontend Simulation

تنفيذ كامل لوثيقة **Halaqat Frontend Master Specification v2**: موقع Web حقيقي قابل للتشغيل
والتجربة يحاكي المنصة من منظور المستخدم، ببيانات وخدمات وهمية بالكامل (Mock) بدل Backend حقيقي.

> **لا يوجد خادم ولا ذكاء اصطناعي حقيقي ولا تسجيل صوت فعلي.** كل البيانات تُولَّد محليًا في
> المتصفح، وكل نتيجة تسميع محاكاة مُعلَّمة بوضوح داخل الواجهة نفسها.

---

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173
```

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | تشغيل بيئة التطوير |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run preview` | معاينة نسخة الإنتاج (المنفذ 4173) |
| `npm test` | اختبارات الوحدة (Vitest) |
| `npm run test:e2e` | اختبارات E2E (Playwright) على سطح المكتب والجوال |
| `npm run test:all` | الاثنان معًا |
| `npm run build:single` | بناء نسخة **ملف HTML واحد** مكتفٍ بذاته (`dist-single/halaqat-app.html`) |

### التشغيل على الجوال

`npm run build:single` ينتج ملفًا واحدًا يحوي كل شيء (بلا أصول خارجية ولا خادم)،
ويستخدم التوجيه بالـhash فتعمل الروابط العميقة وزر الرجوع. يكفي فتحه في أي متصفح
أو رفعه إلى أي استضافة ساكنة.

## ما الذي يعمل فعليًا

- **رحلة كاملة**: Landing → Login → OTP → Dashboard → صفحات الدور → إجراءات → نتائج →
  تقارير → إعدادات → Logout → Login مرة أخرى.
- **خمسة أدوار** لكل منها تنقل ولوحة وصفحات وبيانات وإجراءات مختلفة.
- **المصحف**: سور وأجزاء وبحث وعلامات وآخر موضع وتكبير وتفسير وتلاوة (محاكاة) وتحميل
  للقراءة دون اتصال مع محاكاة قطع الاتصال.
- **التسميع**: اختيار المقطع → تسجيل → مؤقّت وموجة صوتية → إيقاف → تحليل → نتيجة قابلة
  للحفظ، مع بيان صريح أن التحليل تجريبي.
- **الاختبارات**: تعليمات → أسئلة مولّدة → مؤقّت → تأكيد الإنهاء → نتيجة ومراجعة الإجابات.
- **التقارير**: فترات وتصفية ورسوم وجداول ومعاينة طباعة مع رأس وتذييل مخصصين.
- **الإعدادات**: الحساب، المظهر، الإشعارات، إمكانية الوصول، الجلسات، المساعدة.
- **متميزو الشهر**: ترتيب محسوب من نشاط الشهر نفسه (إتقان جلساته، حضوره، عدد جلساته)
  لا من متوسط الطالب العام. يراه المعلم لحلقته والمشرف لحلقاته، مع اختيار الشهر
  الجاري أو الماضي.
- **الطالب المتميز ومساعد المعلم**: المعلم يعيّن متميزًا من حلقته مساعدًا، ثم يوكّله
  بسماع مراجعة زملاء — إمّا يسمّيهم بنفسه، أو يحدد عددًا ويترك للمساعد اختيارهم.
  التوكيل مؤقت وينتهي تلقائيًا باكتمال المهمة.

### الحركة

طبقة واحدة في `src/styles/motion.css` بمنحنى هادئ (`--ease-calm`) بلا ارتداد ولا
دوران ولا وميض:

- **الصفحات** تتلاشى تلاشيًا متقاطعًا. لا انزلاق رأسي عمدًا — انزلاق المحتوى
  يزحزح كل شيء تحت المؤشر لحظة الانتقال فيلاحق المستخدم زرًّا يتحرك.
- **القوائم والشبكات** تظهر متتابعة بفارق ٥٥ms بالشفافية وحدها.
- **الحركة المحسوسة** تُترك لما لا يزاحم التفاعل: نمو أشرطة التقدم والحلقات،
  ارتفاع البطاقة عند المرور، انخفاض الزر عند الضغط، وتوهّجة واحدة عند تمام بند.
- **تقليل الحركة** يوقفها كلها — من إعداد المنصة أو من تفضيل النظام — ويبقى كل
  عنصر في حالته النهائية فلا يختفي محتوى. مقفول باختبارات تقيس `animationName`
  و`opacity` فعليًا.

### الأدوار لا تختلط

ترتيب الأدوار المعتمد في كل الواجهات — مصدره `ROLE_ORDER` في `permissions.js`:
**الطالب ← ولي الأمر ← المعلم ← المشرف ← الإدارة**.

| الإجراء | الطالب | ولي الأمر | المعلم | المشرف | الإدارة |
| --- | :-: | :-: | :-: | :-: | :-: |
| المصحف | ✅ | ✅ | ✅ | ✅ | — |
| التسميع | ✅ | — | — | — | — |
| الحضور والملاحظات | — | — | ✅ | ملاحظات | — |
| طباعة التقارير | — | — | ✅ | ✅ | ✅ |
| إضافة/حذف الطلاب | — | — | — | ✅ | ✅ |
| إدارة المعلمين والحلقات | — | — | — | ✅ | ✅ |
| إدارة المستخدمين والمشرفين | — | — | — | — | ✅ |
| مراجعة طلبات التسجيل | — | إنشاء | — | ✅ | ✅ |
| تعيين مساعد وتوكيله | — | — | ✅ | — | — |
| متميزو الشهر | — | — | حلقته | حلقاته | الكل |

المعلم يعلّم حلقته ويتابعها، ولا يبني تشكيلتها: إضافة الطلاب وحذفهم للمشرف والإدارة.
المصدر الوحيد لهذه المصفوفة `src/config/permissions.js`، وتقفلها اختبارات الوحدة.

### مساعد المعلم — الحدود

المساعد **يبقى طالبًا**. دوره في النظام `student` ولا يُمنح أي صلاحية دور:

- التوكيل نطاقه **مراجعة فقط**، ومحدود بستة زملاء كحد أقصى.
- **من يختار الأسماء؟** المعلم يقرر: إمّا يسمّيهم بنفسه، أو يحدد عددًا (حصة) ويفوّض
  المساعد باختيارهم. وحتى في وضع التفويض يبقى الاختيار محكومًا: من حلقته فقط، وليس
  نفسه، ولا يتجاوز العدد المحدد — والمعلم يرى بجانب كل اسم من اختاره.
- **من يُعيَّن مساعدًا؟** من أثبت جدارته بأحد طريقين: متوسط عام ‏85%‏ فأكثر، أو تميّز
  هذا الشهر بمعايير «متميزي الشهر». التعريف موحّد عمدًا فلا يظهر اسم في قائمة
  المتميزين ثم يُرفض تعيينه بقاعدة أخرى.
- ما يسجّله يُوثَّق باسمه (`recordedByAssistantId`) كمراجعة بتوكيل لا كتقييم معلم.
- لا يسجّل حضورًا، ولا يضيف طالبًا أو يحذفه، ولا يعتمد اختبارًا، ولا يرى صفحات المعلم.
- بانتهاء الأسماء يُغلق التوكيل تلقائيًا، فتختفي صفحة المهمة ورابطها من التنقل
  ويعود الطالب لوضعه الطبيعي. وللمعلم إنهاؤه مبكرًا في أي وقت.

القدرة هنا مبنية على **البيانات** (توكيل نشِط يخصّه) لا على مصفوفة الصلاحيات — وهذا
مقصود حتى لا يتحول التوكيل المؤقت إلى رتبة دائمة.

## الوصول (Accessibility)

مستهدف التصميم والاختبار **WCAG 2.2 AA**:

- HTML دلالي، معالم بأسماء مميزة، عنوان `h1` واحد لكل صفحة، وإعلان تغيّر الصفحة لقارئ الشاشة.
- تنقل كامل بالكيبورد، مؤشر تركيز ظاهر دائمًا، حصر التركيز في النوافذ وإرجاعه بعد الإغلاق.
- لا تعتمد أي معلومة على اللون وحده (أيقونة + نص + لون)، ولكل رسم بياني بديل نصي كجدول.
- لا تعتمد أي معلومة على الصوت وحده — لكل حالة صوتية مقابل بصري.
- إعدادات وصول قابلة للتجربة: حجم النص، التباين المرتفع، تقليل الحركة، والمظهر — وتُحفظ
  في المتصفح.
- احترام `prefers-reduced-motion` و`prefers-color-scheme` من النظام مع الاستجابة لتغيّرهما مباشرة.

## ملاحظات على المحتوى

- **النص القرآني**: السور المتضمَّنة نصها كامل ومحقّق (الفاتحة و93–97 و99–114). بقية السور
  تعرض واجهتها كاملة مع إشعار صريح بأن النص غير متضمَّن في النسخة التجريبية — لا يوجد أي
  نص قرآني مولَّد أو وهمي.
- **التفسير**: نص عرض تجريبي مُعلَّم بوضوح، وليس منقولًا عن مصدر تفسيري.
- **أرقام الصفحات والأجزاء**: إرشادية للعرض حسب ترقيم مصحف المدينة.
- **بقية البيانات** (طلاب، حلقات، جلسات، درجات): مولّدة حتميًا وغير حقيقية.

## الحدود المعروفة

- لا يوجد Backend ولا تخزين خارج `localStorage` الخاص بالمتصفح.
- تحليل التسميع محاكاة حتمية مبنية على المقطع المختار، وليس تحليلًا صوتيًا.
- التلاوة والتسجيل محاكاة واجهة بلا ملفات صوتية أو وصول للميكروفون.
- الأدوار تجربة واجهة فقط ولا تمثل تفويضًا أو صلاحيات حقيقية.
